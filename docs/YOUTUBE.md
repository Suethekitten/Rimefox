# YouTube 字幕（非官方功能）

> 本文对应 README 里原来的「YouTube 字幕」一节。开关在设置页「划词与字幕」里，默认关闭。

## 定位

「YouTube 字幕双语」是**非官方**功能：凛狐与 YouTube、Google 没有任何关联，也未获其认可或支持；YouTube 是 Google LLC 的商标。

## 能做什么

- 打开 CC 字幕后，把字幕显示成「原文 + 译文」；
- 只翻播放位置往后约 90 秒的字幕，看多少翻多少，按观看时长计费；
- 支持人工字幕、自动生成字幕和 YouTube 机翻字幕轨道。

## 稳定性（0.8.5 起）

- 切换目标语言后，字幕会立即按新语言重新翻译，旧语言的请求晚回来也不会覆盖；
- 快速切换视频时，新视频的字幕不必等上一个视频的请求结束；
- 全屏、剧场模式、广告切换或播放器 DOM 重建后，字幕会重新显示，不会永久消失或重复叠加；
- 关闭 CC 或关闭字幕翻译后，YouTube 原生字幕会恢复。

## 限制与风险

- 它读取的是播放器在你的浏览器里**已经加载**的字幕数据，依赖 YouTube 未公开的内部接口，YouTube 改版后可能随时失效。
- **只翻 CC 字幕轨道**。烧录在画面里的硬字幕抓不到：那需要对视频画面做文字识别（OCR），本项目不做；视频没有 CC 轨道时字幕按钮是灰的，这个功能也就不会出现。
- 字幕原文的版权归原作者；译文由你配置的模型生成，可能有误，请勿当作官方字幕转载或分发。
- 默认关闭；使用时请遵守 YouTube 的服务条款。

## 隐私

启用字幕后，当前字幕文字会发给你在设置页配置的接口（只发播放位置往后约 90 秒）。页面主环境的挂钩脚本（`content/youtube-hook.js`）默认加载，但只有在你打开字幕双语后才会发请求。完整说明见 [PRIVACY.md](../PRIVACY.md) 和 [docs/privacy.en.md](privacy.en.md)。
