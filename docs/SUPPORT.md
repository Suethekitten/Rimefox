# 支持与验收

更新：2026-11-06；最新已发布 0.17.4，0.17.5 准备中，尚未宣布 1.0。

| 范围 | 1.0 基础承诺 | 验收条件 / 当前边界 |
|---|---|---|
| 网页、划词、输入翻译、术语与配置 | 纳入 | Chrome / Edge 当前稳定版；Windows、macOS、Linux 的独立 Checks 必须通过；复杂网站仍按兼容限制处理 |
| 无 DRM、可重排 EPUB 2/3 | 纳入 | 导入、取消、阅读、翻译、缓存、恢复及旧书库迁移 |
| YouTube 点播 CC、B 站公开视频官方字幕 | 条件纳入 | 必须有可访问字幕轨；真实页面、已登录与退出登录流程均需留证，假页面不能替代；没有字幕轨时不能承诺翻译 |
| PDF 原版与流式阅读、文本翻译 | Beta | 不把扫描 OCR、表格/公式结构重建或任意 PDF 保真纳入 1.0 基础承诺；旋转页与资源保护有自动回归 |
| YouTube 直播 CC | 实验 | 未完成真实直播验收，不列入正式支持 |
| 医学模式 | 可选辅助 | 术语/数值保留是设计目标；没有足够成对盲评证据证明优于通用模式，不宣传质量提升或临床适用性 |
| OCR | 可选本地组件预览（不随包） | 扫描 PDF 需另装用户授权的系统 OCR 组件：Windows `0.2.0-preview.2` 随 0.17.5 待发布、macOS `0.2.0-preview.2` 随 0.17.2 已发布，均未签名；不纳入 1.0 基础承诺 |

独立 [Checks](../.github/workflows/checks.yml) 在每次 push / PR 执行，与 Release 是否已存在无关。Node 在三系统运行，浏览器核心流程按三系统 × Chrome/Edge 运行；Ubuntu 另跑网页翻译、格式和链接顺序回归。工作流已在 push / PR 运行，但 CI 不能替代真实机器验收，跨平台状态仍为**待验收**。DeepSeek 与 Gemini 已有小样本真实验收；两者结构化句子对齐均回退段落，Anthropic 未配置。已执行的本地结果与真实接口证据只在[本次验收归档](archive/2026-11-04-hardening-0.16.4.md)维护。

配置升级、失败重试、快照恢复及程序回退的承诺见 [UPGRADING](UPGRADING.md)。发布前还必须用最终安装包重复核心流程，确认商店版本、截图和中英文隐私材料对应同一版本；没有通过的项目不能写成“正式支持”。
