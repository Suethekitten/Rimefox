# 视频字幕双语（YouTube / 哔哩哔哩，非官方）

> 开关在设置页「划词与字幕」的「视频字幕」卡片里，默认关闭。一个开关同时控制 YouTube 与哔哩哔哩；没有单独的 B 站开关。

## 定位

「视频字幕双语」是**非官方兼容**功能：凛狐与 YouTube、Google、哔哩哔哩均无关联，也未获其认可或支持；YouTube 是 Google LLC 的商标，哔哩哔哩是其权利人的商标。

它复用同一套字幕翻译能力：由平台来源适配器把站点字幕转换成统一时间轴，再交给同一个翻译调度、缓存和叠层渲染。**不是**两套独立的视频翻译引擎。

## 能做什么

- YouTube：打开 CC 后显示「原文 + 译文」，支持人工、自动生成和 YouTube 机翻字幕轨道。
- 哔哩哔哩普通视频页（`https://www.bilibili.com/video/BV...`）：播放器提供官方字幕轨时，打开字幕后显示「原文 + 译文」。
- B 站支持人工字幕、AI 自动字幕和多语言字幕轨；AI 轨道（如 `ai-zh`）按中文识别，不会当成外语再翻一遍。
- 只翻播放位置往后约 90 秒的字幕，看多少翻多少；拖动、暂停、倍速和全屏都按新位置懒翻译。
- 跟随弹窗 / 设置里的目标语言和趣味风格；目标语言等于字幕语言时交还原生字幕，不产生请求。

## 视频身份与切换

- YouTube 轨道身份包含视频 ID、语言、人工 / ASR 和请求代际。
- 哔哩哔哩轨道身份包含 **bvid + cid + 字幕轨道 ID + 语言**。分 P 切换时 cid 变化，即使 bvid 相同也会换轨；站内换另一个 BV 时 bvid 变化。
- 旧字幕请求晚回来、快速连续换视频、播放器先更新 cid 地址栏稍后更新，都由代际 / 轨道校验拦截，不能覆盖当前视频。
- 播放器 DOM 被重建后会重新写叠层；同一个播放器只保留一个 Rimefox 字幕层。

## 原生字幕恢复

- 接管时只在**当前播放器**加 `rimefox-subs-on` 类，用站点限定的 CSS 隐藏该播放器的原生字幕层；不隐藏弹幕，不影响标题、点赞、投币、收藏、评论等控件。
- 关闭字幕翻译、关闭 CC、播广告（YouTube）或字幕语言等于目标语言时，移除隐藏类并隐藏叠层，原生字幕立即恢复。
- 不往页面写全局 class，不改站点全局字幕相关类名，不注入远程 JS，不用 `innerHTML` 渲染字幕。

## 哔哩哔哩来源与限制

- 页面主环境只在 `www.bilibili.com/video/*`（含 `/zh-Hans/video/*` 等语言前缀）的 document_start 观察播放器自己请求的 `/x/player/(wbi/)v2` 回包；回包里有当前 bvid / cid 和官方字幕轨元数据。
- 字幕文本从官方字幕 CDN（`aisubtitle.hdslb.com` 等白名单 HTTPS 地址）读取；后台取文本时不带 Cookie、不跟随到白名单外主机、限制体积。签名 URL 只用于本次取字幕，不写日志、不保存。
- 页面已有的可信轨道优先；无法确认属于当前 bvid / cid 的回包会被拒绝。旧接口 200 + 空字幕不等于视频一定没有字幕，扩展不会因此伪造或生成字幕。
- 不处理直播、弹幕翻译、画面硬字幕 OCR、音频识别、自动生成新字幕、视频下载或 DRM / 会员限制内容。
- 番剧、第三方嵌入和特殊播放器不做首发保证；只有在其 DOM / 接口结构可靠时才可能兼容。
- 依赖哔哩哔哩未公开的播放器接口和页面结构，站点改版后可能失效；没有可用官方字幕轨时功能不可用，扩展不会绕过登录、会员或付费限制。

## 隐私

启用字幕后，当前字幕文字会发给你在设置页配置的翻译接口（只发播放位置往后约 90 秒）。B 站播放器元数据在本机页面内观察；字幕 CDN 请求由扩展后台发起，不带 Cookie 或登录令牌。完整说明见 [PRIVACY.md](../PRIVACY.md) 和 [docs/privacy.en.md](privacy.en.md)。
