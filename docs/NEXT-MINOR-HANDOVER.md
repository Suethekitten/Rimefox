# 下一小版本交接：0.18.0 PDF 版式预览覆盖

> 编写日期：2026-11-06。编写时基线：0.17.4 已发布，Windows OCR `0.2.0-preview.2` 尚未发布。本文以 0.17.4 的代码行为为对照。
> 当前状态：最新发布版本以 [GitHub Releases](https://github.com/Suethekitten/Rimefox/releases) 为准；Windows OCR `0.2.0-preview.2` 已随 [v0.17.5](https://github.com/Suethekitten/Rimefox/releases/tag/v0.17.5) 发布（未签名测试版），与本文的版式预览工作分开。
> 相关文档：[ROADMAP](ROADMAP.md)、[PDF-HANDOFF](PDF-HANDOFF.md)、[HANDOFF](../HANDOFF.md) §9。

## 0. 这次要解决什么

0.18.0 的主轴是 **PDF「双列版式（预览）」覆盖更多页面**，不是改 PDF 原文，也不是重做 OCR。

基线限制：页面级 `layoutSupported` 会在页面或文字旋转时关闭整页译文覆盖。前三项在开发分支上的行为见 [PDF 维护交接](PDF-HANDOFF.md#版式译文预览)，下面保留范围与验收要求。

用户可见目标：

- 目录页的横向标题可翻译，并与原页码保持成对，不再因为一个竖排标题整页放弃。
- 90° / 270° 的侧边标题能按原角度显示译文；暂时放不下的旋转块保留原文，不整页跳过。
- 未放入版式的文字不再只藏在折叠面板里，页面提示能说明数量和原因，并可展开查看完整译文。
- 图片多、正文少的页面，图注、页码、侧边短文本也能参与版式翻译。

## 1. 范围（必须做）

### 1.1 页面级支持改成块级支持

- 版式预览按文字块判定定位与覆盖条件。一处旋转标题不影响同页可定位的横排块。

### 1.2 旋转文字

- 先支持 **0° / 90° / 270°**；180° 可一并处理，任意角度不承诺。
- 译文容器按原块中心旋转，底色和文字方向跟随。
- 放不下时保留原文并计数，不强行叠字。
- `layoutLines` 需要保留足够的信息（角度、原始坐标、字号），不能只存轴对齐的 x/y 范围。

### 1.3 目录页

- 翻译目录条目的标题，显示时和原页码配对。
- 页码不参与语言翻译，保持数字。
- 目录页的竖排大标题可以保留原文；横向条目必须尝试翻译。
- TOC 块（`kind: 'toc'`）与普通正文共用版式放置逻辑，或至少不因 `toc` 分类整块跳过。

### 1.4 未放置文字的降级

- `data-layout-skips` 已记录 `untranslated / position / background / fit`，继续保留并展示。
- 页面提示从“整页暂不替换”改为：已替换 X 处，未放置 Y 处及原因。
- 提供一个展开入口，直接显示该页「完整文字译文」，用户不用先滚到页面底部找折叠面板。
- 不静默跳过；用户能知道哪些文字没有进入版式。

### 1.5 图片多、正文少的页面

- 页码、图注、侧边短标题要能进入块收集和版式放置。
- 页面主体是图片不应成为整页跳过的理由。
- 保持现有「只覆盖纯色背景」的保守策略，复杂背景仍保留原文。

## 2. 明确不做

- 不做任意角度旋转排版；先覆盖 90° / 270° 侧边文字。
- 不做 PDF 跨页段落合并（留给后续版本）。
- 不做 OCR 竖排古籍、表格结构重建、多栏重排。
- 不新增 PaddleOCR 或其他 OCR 后端。
- 不处理 Windows / macOS 代码签名；Windows 组件仍按未签名预览发布，macOS 组件继续未签名、未公证。
- 不改网页翻译、EPUB 阅读主流程。

## 4. 验证样本

至少覆盖：

1. **Nicaragua Azul 第 12 页（165 页样本）**
   - 竖排 `WHAT CAN WE DO?` 可保留原文或按 90° 显示译文。
   - `06 / WHAT CAN WE DO? / 127` 等横向目录条目翻译，页码保持数字、成对。
   - 不允许整页 0 处替换。
2. **p001 目录页 / r002 目录页**
   - 标题与页码仍成对；目录条目不被拆散。
3. **图片多、正文少的页面**
   - 图注、页码、侧边短文本至少有一部分进入版式；复杂背景保留原文。
4. **扫描页 OCR**
   - 旋转框修正后的 OCR 结果；译文不重叠、不盖住原字残片。
5. **普通水平页回归**
   - 现有 0.17.4 已通过的版式页不回退。

## 5. 风险与约束

- 旋转坐标围绕块中心还是页面中心必须统一，否则缩放 / 双列页面会偏。
- 旋转译文框与未旋转块的碰撞检测要用旋转后的外接框，不能用原始 x/y。
- 字体、字号、行高在旋转容器里要保持可读；放不下时宁可保留原文。
- 页面本身有 `/Rotate` 时，先区分页面旋转和文字旋转，避免二次旋转。
- 现有纯色背景策略不能放宽太多，否则图片页会出现文字盖图。
- 版式预览是可选模式；普通阅读、翻译和缓存不能被这次改动拖慢。
