## 采用的架构：同父原链接节点的事务化重排

本轮不是通用 DOM 重排，也不是克隆译文视图。实现选择：

1. 仅当同一个父元素下存在连续的一段普通正文链接；
2. 非链接原子（引用、notranslate、xref、mention、控件、Ruby）只能在链接区之前或之后，不能交错；
3. 所有链接必须是父元素的直接 A 子节点，没有嵌套链接、交互控件、contenteditable 或已知框架根；
4. 模型目标 token 顺序中的标记位置必须单调；链接目标顺序必须与源顺序不同；
5. 用既有 RenderTransaction 的 move 操作移动原 A 节点本身，不克隆、不重建 href/title/id/事件；
6. 移动后重新取 safeSlot，按目标顺序插入正文 gap，再用实际节点身份、文本和链接标签对应校验；
7. 任意规划或写入失败由外层事务整体回滚，保留原文并记录失败；
8. 恢复时逆序执行 move，恢复原始节点位置、文本、属性与结构。

因此保留了原链接的事件监听、节点身份、href 和点击范围；不是把译文写进链接，也不是把整句变成纯文本。

## 支持边界

本轮实际支持的目标场景：

- 英文维基百科首段：同父平坦链接，含末尾文献引用；
- 两个链接交换、一个链接跨过其他链接、多个链接跨句；
- 英语、中文、日语目标的确定性语序回放；
- RTL 直接链接的确定性交换；
- 事件监听、链接身份、精确恢复；
- 双语与仅译文切换复用缓存，0 次额外请求。

仍安全失败的结构：

- 链接嵌套在 span/strong/em 等包装层中；
- 引用或其他保留原子与链接交错；
- 多行、嵌套链接、contenteditable、已知 React 根；
- 模型标记缺失、错误语言、空回包、无法验证的 slot；
- 阿拉伯语密集链接 fixture 中因嵌套链接/结构交错，本轮继续保留原文并提示切双语；其双语路径仍正确显示模型语序。

阿拉伯语 fixture 不是“只确认页面含中文”：测试同时检查双语可见语序、链接标签与 href 对应、事件、恢复；仅译文在不可安全重排时明确失败，不报告虚假 success。

## 收尾修复（独立 QA 复测后）

- 独立 QA 复测发现：关闭翻译后页面已还原、translated 归零，但诊断计数 inlineReordered 仍保留历史值。
- 根因：该计数只在成功注入时累加，还原 / 重建 / 站点替换路径没有对应的递减或重置；它记录的是会话历史，不是当前页面状态。
- 修复：content/dom.js 新增 DT.reorderedCount()，从仍在生效的渲染记录实时统计；content/main.js 的 dt:status 与 dt:diagnose 直接使用该值，删除累加与无效重置。还原、模式切换、显式重译、动态替换、注入回滚后均归零。
- 回归：Node 调度层、离线自检（还原 / 再次重排 / 站点替换 / 清理）与真实 Chrome link-order E2E（关闭后归零、重复开关、框架替换后归零）均通过。
