PDF E2E 默认使用仓库合成的阅读器样本；`node tools/make-pdf-samples.mjs` 可重新生成。脚本会打印实际加载的扩展 ID 与源目录，本轮在独立 Chrome 配置中直接加载当前工作树。

验证覆盖：

- 中文 → 法语 → 中文；下拉框本身零请求，明确翻译后才发送，切回复用对应文本缓存。
- 更换模型、接口地址、提示词和术语后撤去旧译文；明确翻译使用新配置；切回原配置可复用旧结果；外观变化不清译文。
- 切显示模式与重开阅读页复用缓存；新进入可视范围的未缓存页可以正常请求，不能与同一文本重复送翻混为一谈。
- 旧版无配置身份的缓存不复用；缺少长块切片的结果不保存为完整段落。
- 语言 / 配置切换、关闭书籍与停止期间挂起模型响应；放回旧响应后不写当前视图或缓存、不继续补发。
- 新任务先完成后再放回旧响应，新译文、缓存与进度保持；停止保留已经完成的译文。
- PDF 渲染 / 缩放、搜索 / 跳页、模式切换页码、顶部回到第一页及损坏文件提示。
- EPUB 导入 / 目标语言 / 章节 / 预取 / 缓存 / 删除，以及普通文章、设置、输入框、行内格式和离线 B 站字幕的既有回归。
