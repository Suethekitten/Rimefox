## 真实缺口与方案取舍

冻结 0.11.7 在相同最终新夹具 suite 中为 **245/298**；当前为 **298/298**。53 个失败断言涉及格式丢失、普通链接标签未翻译、保护文字出现在 wire、错误输出写入和故障后未立即回滚，不能理解为 53 个独立产品 bug。旧版已经正确保留的链接节点身份、属性、点击及正常关闭恢复继续保留。详细红灯条目见[基线比较](2026-10-24-inline-fidelity-evidence/fidelity-comparison.json)。

| 方案 | 判断 |
|---|---|
| 现有混合原子 | 最适合引用、Ruby、提及、保护 DOM；单独使用不能映射局部强调 |
| 每个源文本节点独立占位 | 跨语言重排、合并/拆句后节点边界没有可靠语义，不采用 |
| 按字符长度/源词序套格式 | 容易把错误译词加粗，不采用 |
| 有限语义标记 + 现有原子 | 采用；标记只描述本地已知格式，模型给目标范围，严格验证后进入原渲染事务 |

新增 `<fN>` 与原 `<kN>` 组合，不重建翻译引擎。普通 strong/b/em/i/span/code/small/sup/sub 的有限语义差异可随译文重排；语义壳来自本地描述，模型 HTML 不被解析或插入。简单链接只事务改原 Text 子节点，原 A、href、属性、事件不变；复杂嵌套链接保留标签。纯 Ruby 延续独立译文容器，混合 Ruby 延续原子机制。

`kind:protect` 使用空 `<kN></kN>`，notranslate、translate=no、站点排除的完整行内文字保留在本地；引用、提及、Ruby 与复杂链接的必要文字仍可能外发。保护 DOM、不翻译和不外发是三种不同承诺。专业上下文跳过保护祖先；保护页及 Shadow 适配页省略无法可靠关联的 title。用户术语说明、医学术语、缩写和缓存指纹按去标记可见文字匹配，空保护区不被还原进请求。

## 可靠性与独立复核

内容侧与后台共用一份解析器，检查重复/虚假/丢失标记、配对、父子关系、不可变原子和虚构 HTML。全部 f 缺失但原子可信时显示普通译文且不缓存；部分格式或原子错误保留原文、记录 renderFailed，不计成功，页面未变时不重发。同段未发送切片取消；已发出的并发请求仍服从既有取消边界。

缓存增加 opt-in 协议身份，保留 API 协议/地址、模型、目标语言、术语和专业身份；坏条目定向失效，不清空全部缓存。原输入框快照、富文本选区、IME/焦点、并发术语保存和端点隔离测试均保留。

预检在写入前完成；false/throw 都撤回新增事务、注册和渲染记录，活跃注入暂停事务压缩。故障测试覆盖双语插入失败、同单元重试、跨压缩阈值回滚和零残留。格式壳参与自身节点识别；源文本结构/格式在等待期间变化时旧结果零写入。悬停映射限制在本单元，避免共享容器串段。

独立复核发现并修复了：部分保护名称经 title 泄露、Shadow title 旁路、字面 f 干扰普通切片、控件默认单语意外变双语，以及跨格式术语/说明与缓存指纹遗漏。中间尝试的通用邻接快照会误释放小说兄弟段，已撤回，只保留 v1 写入前拓扑预检；旧生命周期断言恢复通过。仅六个明确旧协议容错用例使用显式 legacy fixture，其余旧能力仍经真实采集器，不通过删除断言取绿。

## 性能和请求成本

同一 benchmark 分别冻结历史源和工作树源，记录脚本 SHA256；[比较](2026-10-24-inline-fidelity-evidence/performance-comparison.json)、[历史原始数据](2026-10-24-inline-fidelity-evidence/performance-0.11.7.json)、[当前原始数据](2026-10-24-inline-fidelity-evidence/performance-0.12.0.json)。以下为单次采样，不是统计置信结论；基准不加载方向模块，方向由其他浏览器回归覆盖。

| 场景 | 0.11.7→0.12.0 |
|---|---|
| 500k字单段收集 | 78→95ms，增加局部语义扫描成本 |
| 3000段Ruby收集 | 361.5→394.2ms；两版都有既存>100ms警告，均退出2，不能称性能检查全绿 |
| 10k DOM收集/注入 | 45.7→46.5ms / 222.2→233.6ms |
| 300段格式文章收集/注入 | 6.6→9.3ms / 18.6→26ms；新增节点600→2400，实际保留格式需要更多节点 |
| 150段混合论文收集/注入 | 7→8ms / 9.3→12.2ms |
| 动态更新 | 446.2→451.7ms |

全部场景注入、节点身份和精确恢复通过，单元/重复收集数量及普通场景写入数保持；脚本网络尝试为0。格式文章 wire 增26.1%，论文增16.8%，这是语义标记的实际费用成本。缓存/请求由后台测试及扩展 E2E 验证，不能由直连 DOM 基准推断缓存命中。

扩展 E2E 最终96次成功假接口请求、207条文本，另有2次思考参数兼容400；初版协议分批为108次/207条。相同可见优先级补齐兼容批后减少碎片；6个交错普通/格式段的固定调度回归只需2批。发布前0.11.7旧E2E为83次/201条，场景和提示词已变化，不能据此宣称请求总数不增。协议隔离仍可能使小批数增加，但不为格式额外请求对齐，确定性错误不自动付费重试；有效缓存重用、noCache和在途去重均有回归。

## 限制、发布判断与接手方式

格式同一行、范围不超过600字符、描述不超过120个；包含不可变原子的外层软格式保守放弃。全部标记结构正确也不能数学证明译词语义正确，不按长度强贴格式。复杂链接、分行失配、源保留标记与保护区冲突等情况可保留原文；不会在仅译文模式偷偷改双语。标签语义复制不等于复制站点全部CSS。

0.12.0用户变更摘要：局部格式保真、简单链接标签翻译、保护区数据最小化、格式错误安全终止、双语与仅译文字体/悬停稳定性；完整用户文案见[CHANGELOG](../../CHANGELOG.md)。站点规则进阶和会话级Key仍在后续计划，没有恢复图片/表格WIP，也未重做术语note功能。

当前具备本地候选版本及后续独立验收的条件，不能宣称所有真实网页/真实模型验收完成。用户已指定其他AI接手测试，本轮停止追加；任何后续发布都仍需新的明确批准。

接手先读AGENTS/HANDOFF及引擎§3.5；可执行：


真实模型质量抽样必须另获付费授权，固定实际服务商/精确模型ID并记录；建议快速质量、复核上限0，使用fixture中的strong、nested、article-link、protected、RTL和pre-wrap六段，每段一次、约6–12个小请求。检查目标语序、强调译词、链接可点、保护字不在请求里及关闭恢复；不把假模型通过当成真实语义质量结论。
